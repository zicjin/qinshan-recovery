# StringUtils recovery evidence

`StringUtils` has 53 supplier-facing public/protected entries. The owned implementation preserves the null/empty rules, Unicode whitespace handling, first/last replacement semantics, delimiter and regex split behavior, template replacement, URL encoding, padding, collection/array joins, stream reads, and validation helpers using JDK code and the already-owned `ConvertUtils` and `EncodingUtils` registries. The two exception leaves needed by the family (`FileException`, `UnsupportedException`) are included with their supplier constructor surfaces.

`scripts/tests/test-string-utils.sh` extracts hash-pinned supplier common, browscap, commons-csv, and commons-codec jars from the run artifact, rebuilds the owned framework and exact declaration gate, then compares supplier and owned classes through parentless class loaders. It covers 2,734 observations, including malformed template punctuation, exact owned EncodingUtils-backed reads, browser user-agent filename branches, no-request and request failure behavior, stream lifetime/error semantics, and concurrent request-scope cleanup. `encodeChineseFileName` uses the owned request ThreadLocal bridge under `com.sunwayworld.owned.internal.context`, avoiding a partial `ServletUtils` facade.
